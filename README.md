# 공무원연금 계산기

2010년 이후 임용 공무원의 퇴직연금·퇴직수당·퇴직일시금을 추정하는 정적 웹앱.
서버 없이 모든 계산을 브라우저에서 수행하며 입력값을 외부로 전송하지 않는다.

> 추정치이며 법적 효력이 없다. 정확한 연금액은 공무원연금공단(☎ 1588-4321)에서 확인할 것.

## 실행

```bash
npm install
npm run dev        # 개발 서버
npm test           # 엔진 테스트 (30개)
npm run build      # 정적 빌드
npm run convert-data  # 법령 CSV → src/data/*.json 재생성 (표 개정 시)
```

## 구조

- `src/engine/` — 순수 함수 계산 엔진. UI와 완전 분리
  - `calculator.ts` 3구간 산식·현재가치 환산·역전방지 상한 (reference_engine.py 포팅)
  - `lookup.ts` 이행률표·소득재분배 조회 / `constants.ts` 법령 상수 / `severance.ts` 퇴직수당·일시금
  - `validate.ts` 데이터 불변식 — 개발 모드 부팅 시 실행
  - `golden.test.ts` — `reference_engine.py` 출력과 ±1원 대조 (7케이스)
- `src/data/*.json` — 법령 표 데이터. 원본은 루트의 CSV (표 개정 시 CSV만 교체)
- 법령 근거·출처·검증 이력: `공무원연금_계산기_파라미터_레퍼런스.md`
- 구현 지시서: `SPEC_공무원연금계산기.md`

## 알려진 한계 (SPEC §7)

- 2009년 이전 임용자 미지원 (평균보수월액 자료 필요)
- 군복무 산입분 소득 취급 2건은 법령 미확정 — UI에서 추정 범위로 표시
- 직급·호봉 기반 소득 추정은 미구현 (기준소득월액 직접 입력만 지원)
- 퇴직일시금의 "기여금+이자" 하한은 기여금 이력이 없어 문구로만 안내
